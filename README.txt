장순돌 통합 포트폴리오

사용 방법
1. ZIP 전체를 압축 해제합니다.
2. 최상위 index.html을 브라우저에서 엽니다.
3. projects와 assets 폴더를 함께 유지해야 이미지와 스타일이 표시됩니다.
4. 웹에 게시할 때는 이 폴더 전체를 정적 호스팅에 업로드합니다.

구성
index.html: 메인 소개, 프로젝트 목록, 경력 요약, 회사 기술 블로그 링크
projects/eks.html: EKS GitOps 포트폴리오
projects/oncall.html: OnCall 포트폴리오
projects/litellm.html: LLM Gateway 포트폴리오
assets/site.css: 네 페이지의 공통 디자인
assets/site.js: 목차 강조 및 구성도 확대 보기
assets/eks.css, oncall.css, litellm.css: 원본의 프로젝트별 도식·세부 요소 스타일

원본 보존 및 편집 범위
기존 프로젝트 본문과 도식, 출처를 보존하고 공통 헤더·탐색·스타일을 적용했습니다.
LiteLLM 본문에서 '장접'을 '장점'으로 고쳤습니다.
기술 내용과 성과의 사실 검증은 이번 디자인 통합 작업의 범위에 포함하지 않았습니다.

제출 전 확인사항
OnCall 원본 '수행 내용'에 다음 편집 메모가 있었습니다.
  검토 필요 — 실제 담당 범위에 맞게 수정해 주세요.
이 메모는 공개 페이지에서 이 문서로 옮겼습니다. 원본에 적힌 '1인 수행' 및 수행 범위를 제출 전에 확인하세요.
EKS 상세 수치(13개 네임스페이스·67개 Application 등)는 첨부 원본을 기준으로 보존했습니다.
LiteLLM의 기반 프로젝트와 모델명, 운영 이력도 첨부 원본을 기준으로 보존했습니다.
회사 블로그의 두 번째 글은 다른 구성원이 작성한 활용 사례로 표시했습니다.
